About the Models

This application uses five state-of-the-art machine learning models to predict heart disease risk:

A tree-based model that makes decisions based on feature thresholds. Decision trees are easy to interpret and can handle both numerical and categorical data.

A multi-layer perceptron neural network that can model complex non-linear relationships between features. This model uses hidden layers to learn hierarchical patterns in the data.

Uses a polynomial kernel to classify data by finding the optimal hyperplane that separates different classes. SVMs are particularly effective in high-dimensional spaces.

An optimized gradient boosting algorithm that uses an ensemble of decision trees. XGBoost is known for its performance and speed, making it one of the most popular models for tabular data.

A deep learning model adapted for tabular data. While CNNs are typically used for image processing, this model has been specially configured to detect patterns in medical data.
